## 🏎️ Handling & Brakes Tasks

| Task                                          | Status     | Notes                                                         |
| --------------------------------------------- | ---------- | ------------------------------------------------------------- |
| Inspect brakes & suspension                   | ⏳ Planned | Inspect brakes and suspension. (Identifies issues)            |
| Install lowering springs or coilovers         | ⏳ Planned | Install lowering springs or coilovers. (Lowers ride height)   |
| Replace/upgrade shock absorbers               | ⏳ Planned | Replace/upgrade shock absorbers if needed. (Improves damping) |
| Replace suspension bushings                   | ⏳ Planned | Replace suspension bushings. (Reduces play)                   |
| Install strut bar (optional)                  | ⏳ Planned | Install strut bar if desired. (Increases stiffness)           |
| Replace brake rotors (Brembo)                 | ⏳ Planned | Replace brake rotors. (Better stopping power)                 |
| Install EBC brake pads                        | ⏳ Planned | Install EBC brake pads. (Improved braking)                    |
| Install steel braided brake lines             | ⏳ Planned | Install steel braided brake lines. (Firmer pedal)             |
| Flush brake fluid (DOT 4/5.1)                 | ⏳ Planned | Flush brake fluid. (Removes moisture)                         |
| Recondition wheels (scratch removal, balance) | ⏳ Planned | Recondition wheels. (Better appearance and balance)           |
| Wheel alignment & balancing                   | ⏳ Planned | Align and balance wheels. (Ensures proper tracking)           |
| Initial test drive                            | ⏳ Planned | Initial test drive. (Checks handling)                         |
| Road test (gradual speed)                     | ⏳ Planned | Road test gradually. (Verifies performance)                   |
| Post-test check (re-torque, leaks)            | ⏳ Planned | Check re-torque and leaks. (Ensures safety)                   |
