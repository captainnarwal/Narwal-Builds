## 🔍 Step-by-Step Maintenance Checklist

| Task | Status | Notes |
| ---- | ------ | ----- |
| **Initial Inspection** | ⏳ Planned | Inspect for leaks, hoses, belts, wiring. (Prevents breakdowns) |
| **Compression Test** | ⏳ Planned | Test compression in all cylinders. (Checks engine health) |
| **Engine Flush** | ⏳ Planned | Flush engine before oil change. (Removes deposits) |
| **Drain Engine Oil** | ⏳ Planned | Drain old oil. (Removes contaminants) |
| **Remove & Replace Oil Filter** | ⏳ Planned | Replace oil filter. (Ensures clean oil flow) |
| **Drain Coolant** | ⏳ Planned | Drain coolant. (Prepares for fresh coolant) |
| **Flush Cooling System** | ⏳ Planned | Flush cooling system. (Prevents overheating) |
| **Drain Gear Oil** | ⏳ Planned | Drain gear oil. (Maintains transmission) |
| **Replace Air Filter** | ⏳ Planned | Replace air filter. (Improves air intake) |
| **Replace Fuel Filter** | ⏳ Planned | Replace fuel filter. (Ensures clean fuel) |
| **Replace Spark Plugs** | ⏳ Planned | Replace spark plugs. (Better ignition) |
| **Clean Idle Body** | ⏳ Planned | Clean idle body. (Smooth idling) |
| **Clean Throttle Body** | ⏳ Planned | Clean throttle body. (Better throttle response) |
| **Oxygen Sensor Cleaning** | ⏳ Planned | Clean or replace O2 sensor. (Accurate emissions) |
| **Check/Replace PCV Valve** | ⏳ Planned | Check/replace PCV valve. (Reduces emissions) |
| **Inspect Belts & Pulleys** | ⏳ Planned | Inspect belts and pulleys. (Prevents belt failure) |
| **Inspect Engine Mounts** | ⏳ Planned | Inspect engine mounts. (Reduces vibration) |
| **Full Clutch Kit Replacement** | ⏳ Planned | Replace clutch kit. (Reliable shifting) |
| **Refill Engine Oil** | ⏳ Planned | Refill engine oil. (Lubricates engine) |
| **Refill Coolant & Bleed Air** | ⏳ Planned | Refill coolant and bleed air. (Prevents overheating) |
| **Refill Gear Oil** | ⏳ Planned | Refill gear oil. (Lubricates transmission) |
| **Brake Fluid Flush** | ⏳ Planned | Flush brake fluid. (Better braking) |
| **Power Steering Fluid Change** | ⏳ Planned | Change power steering fluid. (Easier steering) |
| **Inspect/Replace Cabin Filter** | ⏳ Planned | Inspect/replace cabin filter. (Better air quality) |
| **Final Check (Leaks, Idle, Warning Lights)** | ⏳ Planned | Check for leaks, idle, lights. (Confirms all good) |
| **Test Drive** | ⏳ Planned | Test drive vehicle. (Verifies performance) |
| **Post-Drive Check (Fluids, Leaks)** | ⏳ Planned | Check fluids and leaks. (Ensures no issues) |
