## 🏁 Turbo Build Tasks
| Task | Status | Notes |
|------|--------|-------|
| Final engine health check (compression, leaks) | ⏳ Planned | Check compression and leaks. (Ensures engine readiness) |
| Install high-flow air filter | ⏳ Planned | Install high-flow air filter. (Improves airflow) |
| Prototype intake/exhaust manifolds and charge pipe with PVC pipe | ⏳ Planned | Prototype with PVC pipe. (Tests fittings and measurements) |
| Fabricate/install turbo manifold | ⏳ Planned | Fabricate and install turbo manifold. (Routes exhaust to turbo) |
| Mount turbocharger | ⏳ Planned | Mount turbocharger. (Adds boost) |
| Install external wastegate | ⏳ Planned | Install 38mm external wastegate. (Controls boost pressure) |
| Set up oil feed line | ⏳ Planned | Set up oil feed line. (Lubricates turbo) |
| Set up oil return line (weld bung) | ⏳ Planned | Set up oil return line. (Returns oil to engine) |
| Mount front mount intercooler | ⏳ Planned | Mount front mount intercooler. (Cools intake air) |
| Route intercooler piping | ⏳ Planned | Route intercooler piping. (Delivers cooled air) |
| Install blow-off valve | ⏳ Planned | Install blow-off valve. (Prevents compressor surge) |
| Fabricate downpipe | ⏳ Planned | Fabricate custom downpipe. (Exhausts turbo gases) |
| Upgrade fuel pump | ⏳ Planned | Upgrade fuel pump. (Provides more fuel) |
| Install/upgrade injectors (if needed) | ⏳ Planned | Install/upgrade injectors if needed. (Delivers fuel) |
| Install piggyback ECU | ⏳ Planned | Install piggyback ECU. (Manages engine parameters) |
| Wire sensors, install wideband O2 | ⏳ Planned | Wire sensors and install wideband O2. (Monitors air-fuel ratio) |
| Connect all vacuum/boost lines | ⏳ Planned | Connect vacuum/boost lines. (Routes boost signals) |
| Final check (all bolts, lines, leaks) | ⏳ Planned | Check all bolts, lines, leaks. (Ensures safety) |
| First start after turbo | ⏳ Planned | First start after turbo. (Tests installation) |
| Boost leak test | ⏳ Planned | Test for boost leaks. (Finds leaks) |
| Base tuning (low boost, safe maps) | ⏳ Planned | Base tune with low boost. (Safe operation) |
| Proper ECU tuning | ⏳ Planned | Perform proper ECU tuning. (Optimizes performance) |
| Test drive (light throttle) | ⏳ Planned | Test drive with light throttle. (Verifies performance) |
