# 1. Planning

- Define final build goal (turbocharged street build)
- List all major upgrades:
  - Turbo system
  - Wheels & tyres
  - Suspension
  - Braking system
  - Exterior & interior restoration
- Set build order:
  - Maintenance → Power → Control → Aesthetics
- Budget allocation for each section
- Identify parts that must not be duplicated
- Decide turbo approach (low boost on stock engine)
- Plan sourcing:
  - New vs used parts
  - Local fabrication vs branded components
- Timeline planning based on budget and availability

---

# 2. Maintenance

- Engine oil + oil filter replacement
- Gearbox oil replacement
- Coolant flush and refill
- Brake fluid flush
- Power steering fluid check/replacement
- Clutch system:

  - Clutch disc
  - Pressure plate
  - Release bearing
  - Clutch master cylinder
- Ignition system:

  - Spark plugs replacement
  - Ignition coil check
- Air & fuel:

  - Air filter replacement
  - Fuel filter replacement
- Engine health:

  - Compression test
  - Check for oil leaks
  - Sensor inspection
- Belts:

  - Timing belt inspection/replacement (if required)
  - Accessory belts
- Suspension inspection:

  - Bushings
  - Ball joints
  - Tie rods
  - Shock absorbers condition
- Brakes inspection:

  - Rotor wear
  - Brake pads condition
  - Brake lines check
- Electrical:

  - Battery check
  - Wiring and grounding check

---

# 3. Phase1 – Foundation + Turbo Build (BIG TRANSFORMATION)

## Foundation

- Engine health verification (final check before turbo)
- Install new spark plugs (suitable for turbo use)
- Install upgraded clutch kit
- Basic intake setup (high-flow filter if needed)

## Turbo System Installation

- Turbo manifold fabrication/installation
- Turbocharger installation
- Wastegate installation
- Blow-off valve installation

## Air System

- Front mount intercooler installation
- Intercooler piping fabrication and routing

## Exhaust System

- Turbo downpipe fabrication
- Connect downpipe to cat-back exhaust system

## Fuel System

- Fuel pump upgrade
- Injector upgrade (if required)

## Engine Management

- Install piggyback ECU or standalone ECU
- Wiring and sensor integration
- Base tuning setup

## Oil & Boost Support

- Turbo oil feed line installation
- Oil return line setup
- Boost controller installation

## Initial Testing

- First engine start
- Leak checks (oil, boost, coolant)
- Idle and basic tuning adjustments

---

# 4. Phase 2 – Handling + Braking (Control the Power)

## Wheels & Tyres

- Select and install alloy wheels (15” or 16”)
- Install wider performance tyres

## Suspension

- Install lowering springs or coilovers
- Replace/upgrade shock absorbers (if required)

## Stability

- Install strut bar (optional)

## Braking System

### Core Upgrades

- Install larger brake rotors
- Install performance brake pads
- Caliper upgrade or swap (if applicable)

### Supporting Upgrades

- Install steel braided brake lines
- Replace with high-performance brake fluid

## Testing

- Alignment and balancing
- Road testing for stability
- Brake performance testing

---

# 5. Phase 3 : Aesthetics + Final Restoration

## Exterior

- Dent removal
- Panel alignment corrections
- Full body repaint or touch-up

## Body Enhancements

- Install body kit / skirting
- Exterior trim restoration

## Lighting

- Headlight upgrade or restoration
- Install DRLs / auxiliary lighting (if planned)

## Wheels Finish

- Alloy repaint or refurbishment

## Interior Restoration

- Seat cleaning or reupholstery
- Roof liner repair/replacement
- Steering wheel restoration
- Dashboard and trim cleaning

## Final Detailing

- Interior deep cleaning
- Exterior polishing and finishing
