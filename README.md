## 📋 Detailed Build Plan

### Phase 0: Planning & Research

#### Key Objectives
- Define the final build goal: a turbocharged street build
- List all major upgrades needed
- Set the build order: Maintenance → Power → Control → Aesthetics
- Allocate budget for each section
- Identify parts that must not be duplicated
- Decide on turbo approach: low boost on stock engine
- Plan sourcing strategy
- Create timeline based on budget and availability

#### Major Upgrade Categories
- Turbo system components
- Wheels and tyres
- Suspension system
- Braking system
- Exterior and interior restoration

#### Sourcing Strategy
- New vs used parts evaluation
- Local fabrication vs branded components
- Cost-benefit analysis for each category

### Phase 1: Complete Maintenance

#### Fluid Services
- Engine oil and oil filter replacement
- Gearbox oil replacement
- Coolant flush and refill
- Brake fluid flush
- Power steering fluid check/replacement

#### Clutch System
- Clutch disc replacement
- Pressure plate replacement
- Release bearing replacement
- Clutch master cylinder upgrade

#### Ignition System
- Spark plugs replacement
- Ignition coil inspection

#### Air and Fuel System
- Air filter replacement
- Fuel filter replacement

#### Engine Health Checks
- Compression test
- Oil leak inspection
- Sensor inspection

#### Belt and Hose Inspection
- Timing belt inspection/replacement (if required)
- Accessory belts check

#### Suspension Inspection
- Bushings condition
- Ball joints check
- Tie rods inspection
- Shock absorbers condition

#### Brakes Inspection
- Rotor wear assessment
- Brake pads condition
- Brake lines check

#### Electrical System
- Battery check
- Wiring and grounding inspection

### Phase 2: Turbo System Build

#### Foundation Work
- Engine health verification (final check before turbo)
- Install new spark plugs suitable for turbo use
- Install upgraded clutch kit
- Basic intake setup with high-flow filter if needed

#### Turbo System Installation
- Turbo manifold fabrication and installation
- Turbocharger installation
- Wastegate installation
- Blow-off valve installation

#### Air System Setup
- Front mount intercooler installation
- Intercooler piping fabrication and routing

#### Exhaust System Modifications
- Turbo downpipe fabrication
- Connect downpipe to cat-back exhaust system

#### Fuel System Upgrades
- Fuel pump upgrade
- Injector upgrade (if required)

#### Engine Management Setup
- Install piggyback ECU or standalone ECU
- Wiring and sensor integration
- Base tuning setup

#### Oil and Boost Support
- Turbo oil feed line installation
- Oil return line setup
- Boost controller installation

#### Initial Testing Phase
- First engine start after modifications
- Leak checks for oil, boost, and coolant
- Idle and basic tuning adjustments

### Phase 3: Handling & Control

#### Wheels and Tyres Package
- Recondition existing wheels (paint white, balance)
- Install wider performance tyres

#### Suspension Upgrades
- Install lowering springs or coilovers
- Replace/upgrade shock absorbers if required

#### Stability Enhancements
- Install strut bar (optional)

#### Braking System Upgrades

##### Core Components
- Install Brembo brake rotors
- Install EBC performance brake pads

##### Supporting Components
- Install steel braided brake lines
- Replace with high-performance brake fluid

#### Testing and Validation
- Alignment and balancing
- Road testing for stability
- Brake performance testing

### Phase 4: Aesthetics & Final Restoration

#### Exterior Work
- Dent removal
- Panel alignment corrections
- Full body repaint or touch-up

#### Body Enhancements
- Install body kit/skirting
- Exterior trim restoration

#### Lighting Upgrades
- Headlight upgrade or restoration
- Install DRLs/auxiliary lighting if planned

#### Wheels Finishing
- Alloy repaint or refurbishment

#### Interior Restoration
- Seat cleaning or reupholstery
- Roof liner repair/replacement
- Steering wheel restoration
- Dashboard and trim cleaning

#### Final Detailing
- Interior deep cleaning
- Exterior polishing and finishing

## 💡 Key Build Principles

| Principle | What It Means | Why It Matters |
|-----------|--------------|----------------|
| **Reliability First** | Low boost on stock internals (6-8 PSI max) | Ensures engine longevity, no blow-ups |
| **Budget Conscious** | Mix of new, used, and locally fabricated parts | Keeps project affordable, realistic for audience |
| **Educational Focus** | Every step documented, filmed, explained | Viewers learn, not just watch |
| **Progressive Build** | Each phase builds on previous without conflicts | No wasted steps, logical flow |
| **Safety Priority** | Proper maintenance, testing, verification at each phase | Nobody crashes, nothing breaks mid-build |

## 🛠️ What You'll Need

### Core Equipment Categories

1. **Basic Mechanical Tools** (~₹1,500 - ₹3,500)
   - Socket set, ratchets, wrenches, screwdrivers, pliers
   - See [tools.md](tools.md) for complete list

2. **Lifting & Support** (~₹3,000 - ₹6,000)
   - Hydraulic jack, jack stands, torque wrench
   - CRITICAL for safety – don't skip

3. **Specialized Tools** (~₹4,000 - ₹8,000)
   - Brake bleeding kit, compression tester, OBD scanner
   - Required for phases 2-3

4. **Fabrication Equipment** (~₹8,000 - ₹15,000 or outsource)
   - Angle grinder, welding machine or use local fabricator
   - For custom turbo manifold, downpipe, etc.

5. **Diagnostic Gear** (~₹1,500 - ₹3,500)
   - Wideband O2 sensor, boost controller, ECU software

**Total Tool Investment**: ₹20K - ₹40K (or outsource fabrication to reduce)
